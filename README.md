A two-line robot confession for make.fun's "The Robot Apology" bounty ($2 in USDC). Line one apologises for one specific, human-scale mistake — watering the wrong plant — and line two names the lesson that follows from it and the behaviour that changes: reading the label on each pot before pouring.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
